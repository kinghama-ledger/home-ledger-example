# 갤럭시 + MacroDroid 문자·알림 수집 안내

갤럭시 폰에 도착한 결제 문자나 앱 알림을 MacroDroid가 우리 집 가계부의 **수집함**으로 보내도록 설정하는 방법입니다. 먼저 웹앱을 인터넷에 배포하고, **설정 → 문자수집**에서 토큰을 발급하세요. 내 컴퓨터에서만 켠 주소(`localhost`)는 폰에서 닿지 않습니다.

이 문서에는 화면 그림이 없습니다. 화면 그림은 책의 실습 4에 있고, 여기에는 넣을 값만 정리했습니다. MacroDroid의 메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다.

> 문자수집을 켤 때는 배포 환경의 `CRON_SECRET`도 반드시 설정하세요. 이 값이 없으면 30일이 지난 원문을 지우는 정리 작업이 실행되지 않습니다.

## 용어

MacroDroid의 매크로는 세 칸으로 되어 있습니다. 이 문서는 책과 같은 이름을 씁니다.

| 이 문서 | 뜻 |
|---|---|
| 발동(트리거) | 언제 실행할지 |
| 동작(액션) | 무엇을 할지 |
| 요건 | 실행 조건. 이 안내에서는 쓰지 않습니다 |

## 1. 토큰과 주소 준비

1. **폰 브라우저로** 배포한 웹앱에 로그인합니다.
2. **설정 → 문자수집**을 엽니다.
3. **토큰 발급**을 누르고, 노란 상자의 **MacroDroid 용 한 번에 복사**를 누릅니다. 노란 상자는 이때만 보입니다.
4. 칸마다 직접 넣을 때는 같은 화면의 **결제문자 자동수집 설정 방법**을 펼치면 넣을 주소와 값이 나옵니다.

토큰은 요청 헤더 `X-Ingest-Token`에 넣습니다. 잃어버렸다면 기존 토큰을 지우고 다시 발급하세요.

| 보내는 것 | 주소 |
|---|---|
| 결제 문자 | `https://<배포주소>/api/household/inbox/sms` |
| 앱 알림 | `https://<배포주소>/api/household/inbox` |

## 2. 갤럭시 권한 설정

- 문자 매크로: MacroDroid에 **문자 읽기** 권한을 허용합니다.
- 앱 알림 매크로: MacroDroid에 **알림 접근** 권한을 허용합니다. 갤럭시 설정에서 `알림 접근`을 검색해 MacroDroid를 켭니다.
- 공통: **설정 → 애플리케이션 → MacroDroid → 배터리**에서 **제한 없음**을 고릅니다. 하지 않으면 화면이 꺼졌을 때 문자를 놓칠 수 있습니다.

## 3. 결제 문자 매크로

MacroDroid에서 **매크로** 탭의 **+** 를 눌러 새 매크로를 만듭니다.

### 발동

1. **발동** 칸의 **+** 를 누르고 **통화/메시지 → 메시지를 받으면**을 고릅니다.
2. 보낸 사람은 **모든 번호**, 메시지 내용은 **조건 없음**으로 둡니다. 개인 문자까지 넘어가는 것이 싫다면 카드사·은행 번호만 고릅니다.

### 동작

**쉬운 방법 (붙여넣기 한 번).** 1절에서 **MacroDroid 용 한 번에 복사**를 눌러 두었으면, MacroDroid 에서 **동작 + → 웹 접속 → HTTP 요청**을 열고 맨 위 제목 오른쪽 첫 번째 단추(네모 안으로 화살표)를 눌러 뜨는 **cURL 명령어 가져오기** 창에 붙여 넣습니다. 그러면 요청 종류·주소·본문·토큰 헤더가 한 번에 채워집니다. 오른쪽 위 **✓** 로 저장합니다. (MacroDroid 6.0 에서 확인했습니다.)

가져오기가 안 되는 판이면 아래처럼 직접 넣습니다.

1. **동작** 칸의 **+** 를 누르고 **웹 접속 → HTTP 요청**을 고릅니다.
2. **요청 종류**를 **POST**로 바꾸고, **URL 입력** 칸에 문자용 주소를 넣습니다.
3. **Body 내용**과 **헤더 파라미터** 탭에 아래 값을 넣습니다.

| 항목 | 값 |
|---|---|
| 요청 종류 | `POST` |
| URL | `https://<배포주소>/api/household/inbox/sms` |
| 콘텐츠 유형(Content-Type) | `text/plain` |
| Body 내용 | `[sms_message]` |
| 헤더 이름 | `X-Ingest-Token` |
| 헤더 값 | 설정 → 문자수집에서 발급한 토큰 |

`[sms_message]`는 받은 문자의 내용으로 바뀌는 MacroDroid 매직 텍스트입니다. 설정 화면에 나오는 값을 그대로 옮기거나, Body 칸의 매직 텍스트 목록에서 문자 내용에 해당하는 값을 고릅니다.

보낸 번호도 함께 보내려면 콘텐츠 유형을 `application/json`으로 바꾸고 다음 본문을 씁니다.

```json
{"text":"[sms_message]","sender":"[sms_sender]"}
```

문자 내용에 큰따옴표가 들어 있으면 JSON이 깨질 수 있으니, 처음에는 `text/plain`이 더 간단합니다.

저장한 뒤 가상의 소액 결제 예문을 다른 폰에서 보내 보고, 웹앱 **수집함**에 대기 항목이 생기는지 확인하세요.

## 4. 앱 알림 매크로

어떤 은행·카드 알림은 문자가 아니라 앱 알림으로만 옵니다. 그럴 때는 매크로를 하나 더 만듭니다. 앞에서 말한 **알림 접근** 권한이 꼭 필요합니다.

1. **발동** 칸에서 **알림을 받으면**을 고르고 대상 은행·카드 앱을 지정합니다.
2. **동작** 칸에서 **웹 접속 → HTTP 요청**을 고릅니다.
3. 아래 값을 넣습니다.

| 항목 | 값 |
|---|---|
| 요청 종류 | `POST` |
| URL | `https://<배포주소>/api/household/inbox` |
| 콘텐츠 유형(Content-Type) | `application/json` |
| Body 내용 | 아래 JSON |
| 헤더 이름 | `X-Ingest-Token` |
| 헤더 값 | 설정 → 문자수집에서 발급한 토큰 |

```json
{"app":"<앱 이름>","title":"<알림 제목>","text":"<알림 본문>"}
```

`<…>` 자리에는 MacroDroid의 매직 텍스트 목록에서 알림의 앱 이름·제목·본문에 해당하는 값을 골라 넣습니다. 매직 텍스트의 이름은 MacroDroid 버전에 따라 다르므로 이 문서에는 적지 않았습니다.

서버가 읽는 키는 다음과 같습니다.

| 키 | 내용 | 비고 |
|---|---|---|
| `title` | 알림 제목 | `title`, `text`, `bigText` 가운데 하나는 있어야 합니다 |
| `text` | 알림 본문 | |
| `bigText` | 펼친 알림의 긴 본문 | 있으면 `text`보다 먼저 씁니다 |
| `app` | 앱 이름 | 어느 앱에서 온 알림인지 구분합니다 |
| `package` | 앱 패키지 이름 | `app`이 없을 때 대신 씁니다 |
| `receivedAt` | 알림을 받은 시각 | 없으면 서버가 받은 시각을 씁니다 |

알림 본문을 `body`라는 키로 보내면 서버가 읽지 않습니다. 문자용 주소와 달리 알림용 주소는 `text`를 씁니다.

## 5. 확인과 문제 해결

- 웹앱에서 볼 메뉴는 **설정 → 문자수집**과 **수집함**입니다.
- 수집함에 들어온 항목을 확인한 뒤 **확정**하면 거래에 반영됩니다.
- 들어오지 않으면 주소, `X-Ingest-Token`, 배터리 제한, 문자 읽기 권한 또는 알림 접근 권한을 차례로 확인하세요.
- 특정 은행 문자만 계속 잡히지 않으면 채팅+(RCS)로 오는 것일 수 있습니다. 메시지 앱 설정에서 채팅+를 끄거나 앱 알림 매크로를 쓰세요.
- 카드사마다 형식이 달라 금액이나 가맹점이 비어 보일 수 있습니다. 그래도 원문은 수집되므로 수집함에서 직접 고쳐 확정할 수 있습니다.
- 지역화폐 규칙은 가상 이름 '한빛페이' 기준의 예시입니다. 자기 지역화폐 알림에 쓰려면 Claude Code에 "지역화폐 이름을 ○○페이로 바꿔줘"라고 시키세요.
- 요청 형식과 응답 코드는 [SMS_FORWARDING.md](./SMS_FORWARDING.md)에 정리되어 있습니다.

수집된 원문은 `CRON_SECRET`으로 보호된 일일 정리 작업이 30일 뒤 삭제합니다. 토큰과 배포 주소는 다른 사람과 공유하지 마세요.
