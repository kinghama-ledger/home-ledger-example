# 화면 규칙

가계부 화면을 고칠 때 지키는 약속이다. 왜 그렇게 정했는지는 코드 주석(`설계 NN`)에 남아 있다.
목록에서 대화상자를 여는 방식의 세부 규칙은 `CLAUDE.md` 6절에 있고, 여기서는 되풀이하지 않는다.

## 1. 색

색은 뜻이 있을 때만 쓴다. 뜻이 없는 숫자는 검정이다.

| 색 | 뜻 | 쓰는 곳 |
|---|---|---|
| 파랑(`primary`) | 들어오는 돈, 지금 고른 것, 주된 동작 | 수입 금액·수입 막대, 활성 메뉴와 탭, 주 버튼, 통계 카드 `positive` |
| 빨강 | 손을 써야 하는 경고 | 통장 부족액, 통계 카드 `danger`, 오류 상자 |
| 호박색 | 나가는 돈(그래프), 주의 | 출금 예정·이번 달 지출 막대, 통계 카드 `warning`, 마스킹 모드 표시 |
| 검정 | 그 밖의 모든 값 | 지출 화면의 금액(모든 행이 지출이라 빨강으로 칠하면 정보가 아니다), 통계 카드 `default`·`info` |
| 연파랑 · 연주황 칸 바탕 | 통장 주인 구분 | 현금흐름·대출관리의 출금계좌 칸. 주인이 같으면 은행이 달라도 같은 색(`src/lib/household/account-color.ts`) |

- 바탕은 옅은 회색, 카드는 흰색이다. 카드 바탕에 색을 칠하지 않는다.
- 색 값은 `src/app/globals.css` 의 토큰에만 둔다. 토큰 이름은 shadcn 표준 이름만 쓴다.

## 2. 글자와 모양

| 항목 | 값 |
|---|---|
| 글꼴 | Pretendard 하나 |
| 기준 글자 크기 | 15px (`html`) |
| 모서리 | shadcn 기본값(`--radius` 0.625rem) |
| 숫자 열 | `tabular-nums` 로 자릿수를 맞춘다 |
| 누를 수 있는 것 | 손가락 커서(`globals.css` 기본 층, 꺼진 것은 제외). `[tabindex]` 는 넣지 않는다 — 탭 패널 빈 곳까지 손가락이 된다 |

## 3. 통계 카드

| 규칙 | 내용 |
|---|---|
| 내용 | 이름표 + 값. PC 에서만 오른쪽에 아이콘. 설명 줄 없음 |
| 높이 | 내용만큼. 최소 높이 없음 |
| 좁은 화면 | 금액은 `mobileValue` 에 `formatManwon()` 값(예: `1,234만원`) |
| 색 | `tone` 으로만 준다(1절). 일반 지출·출금 카드는 `default` |
| 가림 | 금액·이름 카드는 `sensitive` 에 가림 종류를 줘서 마스킹 모드를 따른다 |

## 4. 표

| 규칙 | 내용 |
|---|---|
| 열 폭 | `hh-board.tsx` 의 `HH_COL` 척도에서 고른다. 비율 폭(`w-[N%]`) 금지 |
| 긴 글 | 자르지 않고 줄을 바꾼다(`truncate` 금지) |
| 표 전체 폭 | 열 폭 합이 본문 최대 폭을 넘지 않게 미리 더해 본다. 넘으면 모든 화면에 가로 스크롤이 생긴다 |
| 표 안 선택 칸 | `.hh-select` 를 쓰고 `pr-6` 이상을 함께 준다(화살표가 글자를 덮지 않게) |
| 좁은 화면 | 표 대신 카드로 바뀐다. 열에 `mobile` 힌트(제목·금액·부가·숨김)를 주면 두 줄로 줄어든다 |

## 5. 탭

| 상수 (`src/components/household/hh-tab-styles.ts`) | 쓰는 곳 | 모양 |
|---|---|---|
| `HH_TAB_SOLID` | 화면의 주 탭 | 파란 칠 + 흰 글자 |
| `HH_TAB_SUB` | 화면 안쪽·카드 안의 하위 탭 | 옅은 파란 바탕 + 파란 글자 |

`<TabsTrigger className={…}>` 에 덧입힌다. `src/components/ui/tabs.tsx` 는 고치지 않는다.

## 6. 대화상자

| 규칙 | 내용 |
|---|---|
| 여는 곳 | 목록 위 등록 버튼과 행 클릭 |
| 하나로 | 등록과 수정을 한 대화상자가 맡는다 |
| 아래 줄 | 오른쪽에 취소와 등록(수정일 때는 수정), 수정일 때만 왼쪽에 삭제 |
| 긴 내용 | 대화상자 안에서 세로로 스크롤된다(7절 보정 1) |
| 저장 뒤 | 대화상자를 닫고 목록만 새로 고친다. 화면을 옮기지 않는다 |
| 알림 | 결과는 오른쪽 아래 알림(sonner)으로 |

## 7. 공식 ui 원본과 다른 곳

`src/components/ui/` 는 shadcn 공식 원본(new-york, neutral) 그대로 둔다. 모양을 바꾸고 싶으면 원본을 고치지 말고 쓰는 쪽에서 클래스를 덧입힌다.
꼭 필요해서 원본에 덧댄 곳은 아래가 전부다. 더 생기면 이 표에 한 줄씩 적는다.

| 번호 | 파일 | 자리 | 덧댄 클래스 | 이유 |
|---|---|---|---|---|
| 1 | `ui/dialog.tsx` | `DialogContent` | `max-h-[calc(100dvh-2rem)] overflow-y-auto` | 입력 대화상자가 화면보다 길 때 안에서 스크롤 |
| 2 | `ui/dialog.tsx` | `DialogFooter` | `flex-row justify-end` | 좁은 화면에서도 버튼을 가로로, 오른쪽에 |
| 3 | `ui/dialog.tsx` | `DialogContent` | 클래스가 아니라 동작: `usePrivacyMode()` 로 가림 여부를 읽어 내용 대신 안내문을 그린다. 속성 `allowWhenMasked` 추가 | 마스킹 모드에서 입력칸의 실제 금액이 보이지 않게. 금액·이름이 없는 창만 `allowWhenMasked` 로 연다 |

`src/app/globals.css` 가 shadcn 기본과 다른 곳.

| 구분 | 내용 |
|---|---|
| 글꼴 변수 | `--font-sans` Pretendard, `--font-mono` 시스템 고정폭 |
| 밝은 화면 색 | 파랑 기조로 가계부가 정한 값. `--radius`·`--destructive`·`--chart-*` 와 어두운 화면 값은 기본 그대로 |
| 기본 층 | 글자 크기 15px, 손가락 커서 |
| `.hh-select` | 표 안 선택 칸의 화살표를 직접 그리는 규칙 2개 |

## 8. 고치기 전에 볼 것

1. 색을 새로 쓰려는가 → 1절의 뜻에 맞는지.
2. 표에 열을 더하는가 → 폭 합계와 좁은 화면 카드.
3. 금액·이름을 새로 보여 주는가 → 마스킹 모드에서 가려지는지.
4. `src/components/ui/` 를 고치려는가 → 쓰는 쪽에서 덧입힐 수 없는지 먼저. 고쳤으면 7절 표에.
