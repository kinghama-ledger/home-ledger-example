CLAUDE.md 의 "🚀 초기 설정 도우미" 절차를 그대로 따라, 사용자를 위해 초기 설정을 한 단계씩 진행해줘.

- 한 번에 한 단계씩 진행하고, 각 단계 결과를 확인한 뒤 다음으로 넘어간다.
- `npx supabase login` · `gh auth login` · `vercel login` 같은 브라우저 인증은 `!` 로 돌리지 말고,
  사용자가 **새 터미널에서 직접** 실행하도록 안내한다. 그 밖의 비대화형 명령은 네가 직접 실행한다.
- DB 비밀번호는 네가 생성해 `.env.local` 에 저장하고, Supabase 키는 CLI 로 조회해 `.env.local` 에 적는다.
  비밀값을 채팅에 다시 출력하지 않는다.
- 예외: `npm run setup:admin` 이 **이번 실행에서 새로 만든 무작위 비밀번호**를 출력하면, 그 ID·비밀번호를 사용자에게 꼭 그대로 보여 주고 "지금 적어 두세요"라고 안내한다
  (스크립트가 저장하거나 다시 알려 주지 않는다. 잊으면 `npm run setup:admin`, 다른 ID 로 만들었다면 `npm run setup:admin -- 그ID` 를 다시 실행해 새로 만든다).
  사용자가 지정한 비밀번호(인자·`ADMIN_PASSWORD`)는 다시 말하지 않고 "지정한 비밀번호로 설정됨"만 알린다.
  화면을 남과 함께 봤다면 로그인 뒤 마이페이지에서 비밀번호를 바꾸라고 안내한다.
- `npm run setup:admin` 뒤에 `npm run seed:demo` 로 가상 가족(김하늘·이바다)의 더미 데이터를 넣을지 물어보고,
  원하면 네가 실행한다.
- 문자수집을 켜면 30일 원문 정리에 필요한 `CRON_SECRET` 등록을 필수 단계로 진행한다.
- Supabase 무료 플랜은 내가 소유자·관리자인 조직을 합쳐 활성 프로젝트 2개다. 다른 프로젝트가 있다면 활성 프로젝트 한도에 포함되는지 확인한다.
- 에러가 나면 메시지를 읽고 원인·해결책을 쉬운 한국어로 설명한 뒤 재시도한다.

지금 0단계(사전 점검: git/node/npm/gh/vercel 버전 확인)부터 시작해줘. Supabase CLI 는 코드를 받은 뒤 1단계에서 설치한다.
