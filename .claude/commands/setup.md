`CLAUDE.md` 2절 "설치"를 읽고 그 순서대로 진행한다.

1. 먼저 2-1 표의 "끝났는지 보는 법"으로 어디까지 돼 있는지 확인하고, 안 된 첫 단계부터 시작한다. 아무것도 없으면 2-2(프로그램 점검)부터다.
2. 한 단계를 하고 결과를 확인한 다음에 다음 단계로 간다.
3. 브라우저 인증(`npx supabase login`, `gh auth login`)은 사용자가 새 터미널 창에서 직접 치게 하고 "했어"를 기다린다. 나머지 명령은 직접 실행한다.
4. 비밀값은 `.env.local` 에만 쓰고 대화에 옮기지 않는다. 단, `npm run setup:admin` 이 이번에 새로 만든 무작위 비밀번호는 사용자에게 보여 주고 적게 한다.
5. 마지막에 접속 주소 · 로그인 ID · 비밀번호를 한데 모아 보여 준다(2-11 의 꼴).
