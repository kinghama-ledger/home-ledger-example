# 우리 집 가계부

무료 전자책 「엑셀 가계부, 8년 쓰고 졸업했습니다」의 독자가 내려받아 자기 가계부를 만들 때 출발점으로 쓰는 예제 앱입니다. 수입·지출·통장이동·할부·대출을 한곳에 기록하고, 다음 달 출금 예정액과 계좌 잔액을 미리 확인할 수 있습니다.

이 저장소의 인물, 계좌, 카드, 대출, 거래는 모두 가상 데이터입니다. 시험에 쓰는 문자 예시는 실제 카드사·은행 문자의 **형식**을 본뜨되 금액·상호·이름을 바꾼 것입니다. 코드 주석의 "실측"은 이 앱을 만들며 화면 크기·글자 폭·행 수·도구 동작을 확인한 개발 기록이고, "실 DB"·"실데이터"는 시험이 연결하는 내 DB 와 그 안의 내 자료를, "실거래"는 예정이 아니라 장부에 기록된 거래를 뜻합니다. "예시 원문"·"사례"·"예시 값"으로 적힌 문자와 금액은 형식만 본뜬 가상 예시입니다. `npm run seed:demo`가 만드는 김하늘·이바다 가족도 실제 사람이나 거래와 관계없는 예시입니다.

> 처음에는 [SETUP.md](./SETUP.md)를 열고 첫 단계부터 따라 하세요. 설치 마지막에 화면에 나오는 관리자 비밀번호는 꼭 적어 두세요(잊으면 `npm run setup:admin` 으로 새로 만듭니다).

## 설치

빈 폴더에서 다음 명령으로 코드를 받습니다.

```bash
git clone https://github.com/kinghama-ledger/home-ledger-example.git .
npm install
```

이후 Supabase 프로젝트와 환경변수, 관리자 계정을 준비하는 과정은 [SETUP.md](./SETUP.md)에 순서대로 설명되어 있습니다. 코딩이 익숙하지 않다면 이 폴더를 Claude Code로 열고 “초기 설정 도와줘”라고 요청해도 됩니다.

## 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 수집함 | 휴대폰에서 들어온 결제·입출금 알림을 검토하고 거래로 확정합니다. 문자수집을 켜지 않았다면 비어 있어도 정상입니다. |
| 현금흐름 | 이번 달과 다음 달의 출금 예정액, 예상 잔액, 부족 가능성을 보여 줍니다. |
| 통장내역 | 계좌별 입출금 내역과 잔액을 통장처럼 확인합니다. |
| 대출관리 | 대출 조건, 상환 일정, 남은 원금을 관리합니다. |
| 거래관리 | 수입·지출·통장이동을 직접 입력하거나 엑셀에서 여러 건을 붙여 넣습니다. 할부도 여기서 관리합니다. |
| 통계 | 월별 현금 흐름과 분류별 지출 추이를 봅니다. |
| 설정 | 계좌, 지출 분류, 인물, 정기지출, 예산, 문자수집 토큰을 관리합니다. |
| 시스템개선 | 개선 이력과 재무 점검 항목을 조회하고, 확인이 필요한 항목을 확인 처리합니다(메모 포함). |
| 마이페이지 | 사이드바 아래의 사용자 이름을 눌러 비밀번호를 변경합니다. |

## 빠른 실행

Supabase 설정을 마친 뒤 다음 명령을 사용합니다.

```bash
npm run setup:admin
npm run seed:demo
npm run dev
```

로그인 ID 는 `admin`, 비밀번호는 설치 마지막(`npm run setup:admin`)에 화면에 나오는 무작위 값입니다. 잊으면 같은 명령을 다시 실행하면 새 비밀번호가 나옵니다.

문자 자동수집은 선택 기능입니다. 앱의 **설정 → 문자수집**에서 토큰을 발급하고 MacroDroid를 연결하면 결제 문자와 알림이 수집함으로 들어옵니다. 자세한 절차는 [갤럭시·MacroDroid 안내](./docs/household/MACRODROID_GALAXY.md)를 참고하세요.

지역화폐 규칙은 가상 이름 '한빛페이' 기준의 예시입니다. 더미 데이터에는 지갑 계좌와 결제수단 `한빛페이(김하늘)`이 들어 있고, 충전 이체와 충전 인센티브 규칙이 이 이름으로 동작합니다. 실제 지역화폐 알림은 이름이 달라 그대로는 맞지 않습니다. 자기 지역화폐에 쓰려면 Claude Code에 "지역화폐 이름을 ○○페이로 바꿔줘"라고 시키세요.

후불교통 규칙도 예시입니다. 이 예제는 은행 출금 문자에 '우리카드결제대금'(줄여 쓴 '우리카드결제대', '우리카드대금', '우리카드대금결제' 포함)이라는 글자가 있으면, 그 출금을 카드대금 납부가 아니라 후불교통 요금으로 보고 지출로 분류합니다. 그 카드를 체크카드로 쓰고 후불교통 요금만 한 달에 한 번 따로 빠지는 경우를 가정한 것입니다. 같은 카드를 일반 신용카드로 쓰는 분은 카드대금이 개별 승인과 겹쳐 두 번 잡힐 수 있습니다. 그럴 때는 Claude Code에 "후불교통 규칙을 빼 줘"라고 시키세요.

수집함의 '토스 이자' 버튼은 이름에 '토스뱅크'가 들어간 활성 계좌가 있을 때 쓰는 예시 기능입니다. 버튼은 계좌 이름에 이 글자가 있는지만 보고 입금계좌 후보를 찾습니다. 더미 데이터에는 그런 계좌가 없어서, 버튼을 누르면 "토스뱅크 계좌를 찾지 못했습니다"라는 안내가 나오고 저장 버튼이 눌리지 않는 것이 정상입니다. 쓰려면 **설정 → 계좌정보**의 '계좌·카드 등록'에서 이름에 '토스뱅크'가 든 계좌를 추가하세요(예: `토스뱅크(김하늘)`).

## 출처와 이용 안내

로그인, 계정 관리, 설치 도우미의 바탕은 윤용승 님의 「윤비서 템플릿」입니다. 그 위에 가계부 기능을 새로 만들었습니다. 자세한 출처는 [NOTICE.md](./NOTICE.md)에 적었습니다.

이 예제는 무료로 공개합니다. 개인 학습용 출발점으로 자유롭게 고쳐 쓰되, 출처를 지우거나 예제 자체를 다시 파는 일은 하지 말아 주세요.
